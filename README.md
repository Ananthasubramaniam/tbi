# Thirupathy Bright Industries (TBI) — Digital Steel Supply Chain Concept

> **PROPOSED PLATFORM — CONCEPT DEMONSTRATION**  
> A cinematic, full-screen frontend concept demonstration for a proposed digital steel supply-chain platform for **Thirupathy Bright Industries (TBI)**, an Indian bright steel manufacturer based in Tamil Nadu, India.

---

## 🎬 Concept Demonstration Overview

This application is designed specifically for creating a **90-second product concept video demonstration** via browser screen recording. It showcases how a modern, connected digital supply chain platform can transform bright steel procurement, inventory visibility, mill traceability, and just-in-time dispatch for precision machining and automotive OEM component manufacturers.

*Note: All data, prices, batch numbers, and mill test certificates shown are illustrative concept mockups and do not represent existing commercial or financial records.*

---

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Dev Server**: Vite 8
- **Styling**: Tailwind CSS v4 + Custom Industrial CAD styling
- **Motion & Transitions**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Plus Jakarta Sans, JetBrains Mono, Syne (via Google Fonts)

## 🚀 Quick Start & Exact Run Commands

### 1. Prerequisites
Ensure you have **Node.js** (v18+) and **npm** installed.

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your desktop browser.

### 4. Build Production Bundle
```bash
npm run build
```

### 5. Preview Production Build
```bash
npm run preview
```

## 📺 The 7-Scene Narrative Flow (90 Seconds Total)

| Scene | Duration | Title | Key Highlights |
|---|---|---|---|
| **Scene 1** | ~12s | **Brand Introduction & Platform Vision** | Official TBI logo placeholder, headline *"The Future of Steel Supply Chains"*, core architectural pillars. |
| **Scene 2** | ~14s | **Digital Procurement** | 3 verified bright steel listings (EN8D, EN1A, 20MnCr5), **750 kg small-order demonstration (₹56,100)**, simulated instant order confirmation & PO generation. |
| **Scene 3** | ~13s | **Enterprise Inventory Visibility** | Dark enterprise dashboard showing **1,420 MT live stock**, 3 warehouse hubs (Sriperumbudur, Hosur, Coimbatore), and multi-grade batch filtering. |
| **Scene 4** | ~14s | **Material Traceability** | Physical steel bundle tag with encrypted QR code, laser scanning animation, and verified **EN 10204 3.1 Mill Test Certificate** with chemical & mechanical properties. |
| **Scene 5** | ~13s | **Just-In-Time Dispatch** | 4-stage progression timeline (Reserved → QA Cleared → Automated Weighbridge → Dispatch Scheduled) with telematics & vehicle gate pass. |
| **Scene 6** | ~12s | **Future Opportunities** | Two restrained panels: **Surplus Inventory Marketplace** (secondary off-cut exchange) and **Warehouse Inventory Financing** (e-NWR working capital credit). |
| **Scene 7** | ~12s | **Executive Closing** | Return to TBI logo placeholder, headline *"Building a More Connected Steel Supply Chain"*, recap pills, and replay control. |

## 🕹 Interactive Controls & Keyboard Shortcuts

| Key / Control | Action | Purpose |
|---|---|---|
| `Spacebar` | **Play / Pause** | Toggle automatic 10–15s scene progression timer |
| `→` (Right Arrow) | **Next Scene** | Advance immediately to next scene |
| `←` (Left Arrow) | **Previous Scene** | Return to previous scene |
| `F` | **Presentation Mode** | **Hides all UI chrome, dock, and headers** for clean screen recording |
| `R` | **Replay** | Restart demonstration from Scene 1 |
| `1` to `7` | **Direct Jump** | Jump directly to any of the 7 scenes |
| `?` | **Help Modal** | Open shortcuts guide |
| `Speed (0.5x / 1x / 1.5x)` | **Pacing Selector** | Adjust concept video speed for voiceover or quick review |

## 🎥 Screen Recording Instructions

1. Launch `npm run dev` and navigate to `http://localhost:5173/` in Google Chrome or your recording browser.
2. Maximize the browser window to full screen (`F11` or full screen zoom).
3. Press **`F`** to engage **Presentation Mode**. All navigation bars and browser chrome will disappear, leaving a clean 16:9 full-screen experience.
4. Press **`R`** to begin at Scene 1.
5. The presentation will automatically advance through each scene smoothly over ~90 seconds. You can pause anytime using **`Spacebar`**.
6. When completed, press **`F`** again to exit Presentation Mode.
